# aliyundrive-batch-rename

阿里云盘网页端批量重命名脚本

Fork 自 https://github.com/panghujiajia/aliyundrive-batch-rename

原作者似乎已不再维护，我拿来进行一些修改和优化，适应自己的需求:

 - 精简了一些UI元素, 调整按钮位置到右上角;
 - 优化窗口显示逻辑, 防止溢出屏幕;
 - 支持对文件夹进行批量重命名;
 - 文件列表太长时能自动触发滚动并向下加载;

安装地址: https://github.com/sherlocknieh/alipan-batch-rename/raw/dist/alipan-batch-rename.user.js
